# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/Interior-Designer-Pro.git
cd Interior-Designer-Pro
```
Copiar a pasta `.agents/skills/interior-designer-pro` para o projeto alvo. Para hosts sem descoberta automática, carregar SKILL.md explicitamente. Não depende de serviço Nano Banana para escrever prompts. Não fornece conta, credenciais ou assinatura de editor.
Atualizar: preservar alterações locais, consultar CHANGELOG, atualizar pasta e repetir verificações do README. Não inferir funcionamento de visão só pela instalação.
